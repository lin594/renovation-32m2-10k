## 电气图分工

- `30`只表达点位：两台空调、洗烘机的设备级漏保候选，卫生间末端漏保和扫地机/沙发两个插座。
- `31`只表达真实空间路径：MCB-04合并非卫浴照明；MCB-05只经E-HOLE-03进入卫生间并先接RCD-BATH-01；阳台仍无永久供电。
- `32`只表达保护拓扑：恰好三个RCBO和两个MCB；六个PCT逻辑节点不等于实物采购数量；原JB-L5删除，新增JB-BATH。
- `33`只表达卧室明盒、暗盒和吊扇既有暗线。
- `34`只表达卫生间：漏保箱前连续无分支，浴霸、除雾镜柜、照明全部在双极30mA漏保下游；室内无合格干区时自动移到走廊A门外。

## 两线制边界

- 已确认户内只有L/N、无可用PE且无法由四楼单户独立增设。
- 三孔面板PE端子保持未连接并粘贴“本户无PE”标识；不得N/PE短接或借用水管、燃气管。
- 分级漏保降低风险但不替代PE；上下级可能同时跳闸，须分别实测并记录。
- 全部图纸均为讨论图，不替代现场负载核算、施工图或专业通电验收。
