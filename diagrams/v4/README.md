# V4 图纸职责

V4 使用同一套户型坐标和公共底图。每张图只回答一个专业问题，避免“什么都画、什么都看不清”。

| 文件 | 回答的问题 | 明确不画 |
|---|---|---|
| `00-existing-survey.svg` | 固定空间、墙体、洞口、窗户和已确认现场点位在哪里？ | 家具采购方案、假定线路 |
| `10-furniture-circulation.svg` | 家具家电如何摆、哪些未购买、通道是否畅通？ | 给排水和燃气路线、挡路的待定门扇 |
| `20-plumbing-gas.svg` | 冷热水、排水、地漏和两条燃气支路如何连接？ | 家具软装、完整强电回路 |
| `30-electrical-low-voltage.svg` | 强弱电点位、暗盒、洞口、设备和网络入口在哪里？ | 未确定的最终线槽路线和线径结论 |
| `31-electrical-routes.svg` | 四个穿线孔后的真实空间路径怎么走，设备架贴哪面墙，吊扇哪段明装/暗埋，阳台边界在哪里？ | PCT内部拓扑、最终线长和通电批准 |
| `32-electrical-topology.svg` | 五个既有支路怎样经过PCT节点分支，14组插座如何归属，32A门禁是什么？ | 空间比例、线槽转角和现场安装高度 |
| `33-bedroom-electrical-detail.svg` | 原暗盒调速器、床南/床北明装插座怎样分盒、分回路和接短尾线？ | 其他房间点位和全屋回路总览 |
| `40-doors-windows-cats.svg` | 门窗如何选购/定制，三猫防逃如何验收？ | 家具和水电管线 |

## 移门表达规则

- 家具与动线图只显示卫生间门洞和常闭状态，保持日常动线可读。
- 门窗图和厨卫详图同时表达关闭状态与向东开启状态：门板完全开启名义停在 `y[3.75,4.45]`，约0.4m临时侵入走廊B。
- 实际使用可只滑到够人进出，不要求每次完全开启；定制前仍需复测轨道、门板和有效净宽。

## 状态图例

- 实线：已有、固定或已确认。
- 橙色虚线：计划但未购买/未定制。
- 红色：存在安全或尺寸阻断项。
- 蓝色：水、电或弱电等专业点位，含义以各图图例为准。

## 电气图分工

- `30`只表达现场点位、既有暗盒、四个穿线孔、玄关设备架和EVE V短网线关系。
- `31`表达真实空间走线和不可穿越边界：设备架背面贴走廊A南墙，阳台无穿线孔且本期无永久220V；卧室吊扇的门洞后明线与既有暗埋线用不同线型。
- `32`表达五回路和PCT拓扑：3个漏保、2个空开恰好五路；PCT-42在用1只、PCT-62在用5只，另有PCT-62备用1只不画成在用节点。
- `33`只表达卧室：原西墙暗盒仅装调速器，床南相邻明盒和床北明盒属于卧室漏保常电回路，不与吊扇控制共盒、共槽或共端子。
- 灯具的分区开关不等于配电箱新增回路。保护器铭牌、线径、PCT直接上级额定值和线槽填充须在10月1日现场复测后冻结。
