# 开封32㎡最终明装电路施工方案

**版本：2026-09-30**  
**状态：墙面路线、分支位置、线槽施工语言冻结；现场尺寸仍以实际放样为准。**

本文件是本轮强电明装的**施工入口**。旧的 2026-09-29 五路文档已经被本文件替代；旧强电图 30～37 仍保持退役。墙面路线看 [38 五路最终墙面走槽图](../../diagrams/38-five-route-electrical.svg)；每个节点的几进几出、复杂接法和材料复算看 [39 九节点接线与材料复算图](../../diagrams/39-electrical-node-schedule.svg) 与 [节点接线表/材料复算](2026-09-30-electrical-node-and-takeoff.md)。

## 1. 已冻结的前提

- 配电箱位于 y=5 墙、卧室门与入户门之间的高位门垛。
- 全屋新增线路均走明线槽；既有四个暗盒没有可利用暗管。
- 主干默认走**侧墙高位**，不把天花板平面作为常规走槽面。普通墙以线槽上沿距天花约 50mm 为放样基准，可按墙面平直度和障碍在约 30～80mm 内统一调整。
- 线槽只做横平竖直；90°转弯、两段线槽续接、绕门框都不因为“转弯”增加接线盒。
- 只有导体真正发生接续、分叉、换线径时才形成电气分支节点。
- 卧室吊扇确定拆除，不再提供新电源。原调速器暗盒以后盖空白盖板；原吊扇暗线两端断开、分别绝缘封护，不纳入新回路。
- 阳台本期仍不做永久 220V 穿线。
- 现有无 PE 条件不变；任何三孔面板不得将 N 与 PE 短接。
- 本文件冻结的是**物理路线和施工节点**。保护器额定值、第五路剩余电流保护的最终器件形式、空调/浴霸铭牌适配和通电验收仍执行 data/electrical.yaml 的保护门禁；未完成门禁前，新线路保持断开。

## 2. 统一施工层次

从墙体向外的推荐顺序：

1. 基层处理、墙固/S2 等已确定前置工序完成；
2. 全屋高位弹线与障碍碰撞测试；
3. 先钉**空线槽底座**，不穿线、不扣最终盖板；
4. 挂网、腻子可收到线槽底座两侧，但不得堵住盖板卡槽；
5. 打磨、乳胶漆；底座外缘刷到漆无妨；
6. 墙面达到允许安装的干燥状态后，再穿线、装端子/器具、扣盖；
7. 最后做端接、标识、测试和通电验收。

这样既能让底槽被找平层“吃掉”一部分，降低明装突起，也保留盖板可拆维护。

## 3. 配电箱出来后的总骨架

### 3.1 北向：①卧室 + ②厨房

从配电箱向北，两路沿 y=5 墙高位并行：

- ①卧室在卧室门头处先分离并进入卧室；
- ②厨房继续向北，到厨房门区域后再转入厨房。

两根槽并行时，建议把“继续走得更远”的②厨房放得更靠近顶角，①卧室放在其下方，避免①在卧室门头退出时和②交叉。

### 3.2 南向：③客厅生活 + ④客厅空调/冰箱 + ⑤卫生间

从配电箱向南，三路经过入户门门头，到玄关南侧，再统一向西。

这段公共墙面建议从靠顶到靠下排列为：

1. ④客厅空调+冰箱；
2. ③玄关/客厅生活；
3. ⑤卫生间。

三路保持电气独立。当前 DIY 基线是**三根独立四分槽并排**，而不是把三路硬塞入一根四分槽。

到客厅通道附近开始分流：

- ③、④经通道进入客厅；
- ⑤不深入客厅，在通道/门头位置转向卫生间门墙。

## 4. 第一路：卧室

### 4.1 实际路线

配电箱 → 向北 → 卧室门头 → 绕门框进入卧室 → 沿卧室西墙高位继续向北。

设置两个电气分支位置：

**B1：卧室门内/JZ-N2 上方高位**

- 卧室 JZ-N2；
- 床南/近门常电；
- 主干继续向北。

**B2：床头/卧室空调附近高位**

- 卧室空调；
- 床北常电；
- 第一路在此结束。

卧室吊扇和旧调速器不再属于任何新分支。

## 5. 第二路：厨房

### 5.1 实际路线

配电箱 → 与①一起向北 → ①在卧室门退出后②继续 → 到厨房门区域 → 沿厨房门头进入 → 厨房入口东侧高位 → 沿高位向西 → 到西墙后按设备位置短距离转向。

**K1：厨房入口/主灯高位**

- 厨房基础灯；
- 入口机械开关；
- 主干继续向西。

**K2：厨房西墙高位**

- 洗碗机/电饭煲/预留家电组；
- 台面/油烟机/未来设备组。

不要为每个插座单独增加高位盒；同一局部设备组在满足器具端子和盒内空间要求时可利用相邻器具盒完成短距离贯通。

## 6. 第三路：玄关与客厅生活

### 6.1 玄关

配电箱 → 向南跨入户门门头 → 到玄关南墙 → 向西。

**H1：玄关设备架上方**

- 光猫/Wi-Fi/EVE V 常电；
- 玄关灯带/开关；
- 主干继续向西。

### 6.2 进入客厅

继续向西到客厅通道 → 沿侧墙/门头向北绕入客厅，不跨天花板平面。

**L1：客厅东南/入口高位**

- 洗烘一体机；
- 餐桌附近插座；
- 客厅 JZ-N2 与主灯/餐灯；
- 主干继续沿客厅高位向西。

随后沿客厅南侧高位向西，到西墙后转向北。

**W1：客厅西墙高位**

- 书桌上/下常电；
- 扫地机、沙发上部充电、背景光局部组；
- 投影仪高位常电。

W1 后不再为书桌、扫地机、投影分别设置三个大分线盒；末端尽量用独立 BVVB 下落或符合器具说明的局部贯通。

## 7. 第四路：客厅空调 + 冰箱

路线：

配电箱 → 向南 → 入户门头 → 玄关南墙向西 → 与③并行进入客厅 → 沿客厅南侧高位走最短墙边路径 → 到空调/冰箱上方结束。

**A1：客厅空调/冰箱上方高位**

- 一支去客厅空调；
- 一支去冰箱。

④与③可以相邻并行，但不得共用 N、端子或保护器。

## 8. 第五路：卫生间

路线：

配电箱 → 向南 → 入户门头 → 沿玄关南墙向西，暂时与③④并行 → 到客厅通道附近时脱离 → 利用通道侧墙/门头向北 → 沿卫生间南墙高位向东 → 从卫生间门头进入。

卫生间移门在走廊侧滑动，因此⑤必须保持在移门轨道和门板运行范围上方，不和未来轨道占位冲突。

**BATH1：卫生间高位、尽量干区且可检修**

- 浴霸；
- 浴室柜/镜柜/镜灯；
- 独立卫生间主灯。

卫生间主灯保留，浴霸照明只作为辅助，不作为唯一主照明。

## 9. 分支节点：最终执行规则

### 9.1 什么地方不设盒

以下情况都只是“机械路径变化”，不设接线盒：

- 90°转弯；
- 线槽两米一段的续接；
- 绕门框；
- 同一根完整导线从一个槽段进入下一槽段；
- 不发生电气接续的线路交汇。

正常把两段线槽拼接即可。

### 9.2 什么地方才需要接线空间

只有出现以下情况才设电气节点：

- 一进二出或一进多出；
- 主干继续，同时分出末端支路；
- 6mm²缩到2.5mm²；
- 导线接长；
- 多根灯控/中性线需要正规并联。

当前计划的电气分支位置最多为：

B1、B2、K1、K2、H1、L1、W1、A1、BATH1，共 **9 个位置**。

“9个分支位置”不等于“9个100×100大白盒”。

### 9.3 PCT-42 两版现场实现

已购/候选 PCT-42 标称约 39.5×23.4×14.6mm，可接硬线至 6mm²。明天必须用**真实四分线槽 + 已剥好的真实导线 + PCT-42**试装。

**A版：空间足够**

如果 PCT-42 连同插入后的导线弯曲半径能够自然容纳、盖板无需强压，节点优先采用低轮廓的线槽配套接线/分线构件或短段加宽的可独立开盖分线腔，使视觉上接近线槽本体。

**B版：空间不足**

若端子本体、导线弯曲或盖板任一项放不下，则该节点增加小型明装接线盒：

- 纯2.5mm²简单分支优先86深明盒/小型分线盒；
- 6mm² + PCT + 多条支路优先约100×100×50或能满足弯线空间的更大规格。

普通四分线槽即使几何上能塞入端子，也不把“线槽本体内部随便塞一个接头”作为默认施工做法；接头应有独立、可固定、可重新开盖检查的接线空间。

## 10. 线槽高度与罗马杆两版

### 基准

- 主干都钉在**侧墙上部**，不是天花板平面。
- 默认线槽上沿距顶约50mm；同一面墙尽量一条水平基准。
- 不为某一个障碍做“下去—绕过—再上来”的蛇形。

### 罗马杆 A版：不冲突

若罗马杆支架和50mm高位基准互不冲突：

- 罗马杆本体先拆；
- 支架若易拆也先拆，保留并标记原孔；
- 腻子/乳胶漆正常完成；
- 线槽保持统一高度；
- 最后原位复装罗马杆。

### 罗马杆 B版：发生冲突

优先保持电线槽笔直：

1. 如果罗马杆允许移动，后续把整组支架统一下移/调整；
2. 如果罗马杆原位置必须保留，则**整面墙这一段线槽统一降低**到支架下方，只在墙角做一次高度转换。

不要逐个绕支架做蛇形线槽。

## 11. 明天放样与钉槽顺序

1. 拿一根2m四分槽底座做全屋高位碰撞测试；
2. 先确定统一基准高度和罗马杆 A/B 版；
3. 钉北向①②骨架；
4. 钉南向③④⑤骨架；
5. 钉③④进入客厅后的长主干；
6. 钉⑤去卫生间的门头/侧墙路径；
7. 再标出 B1/B2/K1/K2/H1/L1/W1/A1/BATH1；
8. 最后才钉各插座、开关、灯具的垂直下落支槽。

底槽内部用永久记号笔标：

- C1-BED
- C2-KIT
- C3-LIV
- C4-AC-FR
- C5-BATH

这样即使之后腻子和乳胶漆把外观统一掉，打开盖板仍能立即识别回路。

## 12. 材料数量以节点复算表为准

本方案改变了物理路线后，旧下料表已经失效。当前采购级复算冻结为：

- 四分线槽目标总量40m；已购20m，建议再补20m；
- 6mm²每极净约21.2m，按约25m下料；L买30m，现有约60m蓝色N候选足够；
- BVVB 2×2.5净约63.5m，按约80～85m下料，采购100m；
- PCT-42 18只实际使用+2只备用，共20只；
- PCT-62当前0只刚需；
- 2孔2.5mm²小端子5只、4孔2.5mm²并联端子6只；
- 护套线卡扣目标180～200只，现有100只，支线多数直接卡扣固定时再补100只。

详细计算与每个节点的实际进出线见 [2026-09-30 节点接线与材料复算](2026-09-30-electrical-node-and-takeoff.md)。真正剪线前再以明天墙面实测值更新净长。

## 13. 通电门禁

路线施工完成不等于可以通电。至少仍需确认：

- 2.5mm²末端的过流保护匹配；
- 两台空调、洗烘、浴霸等设备铭牌与插头规格；
- 卫生间全部负载处于不大于30mA的剩余电流保护下游；
- 端子允许导体截面、剥线长度和紧固状态；
- L/N极性、绝缘、漏保TEST及专业动作测试；
- 无PE标识和三孔面板PE端子保持悬空，严禁N/PE短接。

本文件允许业主先完成断电状态下的放样、底槽、末端盒和可逆机械安装；最终端接和通电仍按项目既有验收门禁执行。
