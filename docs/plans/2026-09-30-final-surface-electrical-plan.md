## 1. 已确认条件与计划边界

- 全屋新增线路均明装；现场四个既有位置只是暗盒盒位，**没有可利用暗管或暗线**。
- 户内为L/N两线制、无可用PE；禁止N/PE短接、借水管/燃气管接地。三孔面板PE端保持未连接并持久标识“本户无PE”。
- 现有主配电箱箱体及前四路器件保留；新2.5mm²线路的过流保护按项目既定副保护盒/C20门禁执行。第五路剩余电流保护仍按“主箱原位合适则原位，否则门外DIN小箱”二选一核验。
- **6mm²是前三路的高位主干。2.5mm² BVVB是末端护套支线，不称作主干。**
- 第④客厅空调+冰箱、第⑤卫生间在副保护盒C20之后本身就是短距离2.5mm²馈线，不与前三路6mm²主干概念混用。
- 主干通常走侧墙高位；客厅L1至W1例外按业主9/30 QA沿未来隔帘线横穿并兼顾主照明，横穿构造/标高待放样；90°转弯、续槽、绕门框只是机械路径变化，不因此增加接线盒。
- 只有真正发生导体分叉、接续或缩径的位置才是电气主节点。
- 卧室吊扇拆除，旧调速器盒盖空白盖板，旧暗线不复用；阳台本期不做永久220V。

## 2. 配电箱后的五路骨架

### ① 卧室 RCBO-01
配电箱/副保护盒 → **6mm²**向北 → 卧室门头 → B1 → 沿卧室西墙高位 → B2结束。
- **B1**：6mm²继续B2；2.5→卧室JZ-N2；2.5→床南常电。
- **B2**：2.5→卧室空调；2.5→床北常电。

### ② 厨房 RCBO-02
与①并行向北，①在卧室退出后②继续 → 厨房入口 → K1 → **6mm²**继续到西墙K2。
- **K1**：6mm²继续K2；另一输出负责厨房基础灯/入口机械开关。
- **K2**：主干终止，分两条2.5支线：厨房西南设备组；台面/油烟机/预留设备组。
设备组内部相邻插座在本地可检修明盒内分配，不再创建额外全屋节点。

### ③ 玄关 + 客厅生活 RCBO-03
配电箱/副保护盒 → **6mm²**向南 → 入户门头 → 玄关南墙H1 → 客厅入口L1 → 6mm²按业主已确认的**先向北、再向西**方向去W1。9/30 QA进一步确认：**沿未来沙发临时客卧隔帘位置横穿，线槽兼顾客厅主照明**。路线意图为confirmed；精确标高/位置、W1及长度仍为 **TBD**，图上虚线是示意而非施工坐标。主灯出线与既定JZ-N2控制分工衔接待放样，不凭“兼顾”新增支路；帘轨和灯具固定不默认由线槽承重。先北后西方向最初依据：2026-09-28用户消息 `d9e47c82-5e65-4e18-8672-f73c59727c46`。
- **H1**：6mm²继续L1；2.5→玄关设备架；2.5→玄关灯带/开关。
- **L1**：6mm²继续W1；2.5→洗烘/小厨电区域；2.5→客厅JZ-N2。
- **W1**：三条2.5支线分别去高位投影仪、沙发娱乐区、书桌区域。

沙发娱乐区是一条2.5支线到局部可检修盒，再分给扫地机器人低位常电和置物台上部常电；背景灯以后直接使用上部插座，不另建固定背景灯支路。书桌同样是一条2.5支线到书桌区域，上/下插座在本地分配。

**走廊B：独立灯暂时取消，供电分配待办done。** 9/30 QA确认由走廊A长灯条照明整个走廊，开关在入户门与卧室门之间。不再为B灯新增分线和开关；A灯条具体型号、亮度覆盖及开关导体仍待核验。

### ④ 客厅空调 + 冰箱 MCB-04
与③物理路径相邻但电气完全独立。副保护盒C20后用BVVB 2×2.5沿最短墙边路径到A1。
- **A1**：一支客厅空调；一支冰箱。

### ⑤ 卫生间 MCB-05
副保护盒C20后用BVVB 2×2.5沿玄关公共墙段，到客厅通道附近脱离，转向卫生间门墙并进入BATH1。所有卫生间负载必须位于2P、≤30mA剩余电流保护下游。
- **BATH1**：浴霸；浴室柜/镜灯；独立卫生间主灯/机械开关支路。

## 4. 末端局部分配

厨房两个设备簇、洗烘/小厨电区域、沙发娱乐区和书桌区域允许在可检修明盒/组合盒内做短距离2.5mm²局部分配，但不再赋独立节点ID。不得用插座螺丝端子承担多根不适配导线的“串接总线”。

## 5. 灯控阻碍与后续施工顺序

- 玄关9/30 QA确定普通实体开关、不考虑智能控制，位置在入户门与卧室门之间；卧室/客厅JZ-N2仍需真实L/N。玄关不以智能升级为目的预留N，具体导体配置仍由实际器具与专业核验确定。
- 一根两芯BVVB作机械开关L下行/Lsw返回，仅为待专业确认候选，不能同时预留N。其他机械开关是否保留N由业主确认；蓝芯重标Lsw须按实际产品说明及合格电工意见确认，未通过不得实施。
- 取消旧单芯回线采购不代表替代方案已经获准；导体方案闭合后更新线量。

以下仅为门禁通过后的计划顺序：

基层/墙固/S2完成 → 高位弹线与碰撞检查 → 安装空线槽底座 → 挂网/腻子/打磨/乳胶漆 → 墙面干燥后穿线、装端子和器具 → 扣盖、标识 → 最后验收后通电。

线槽上沿默认距顶约50mm，可按墙面和罗马杆等障碍整段统一调整；不做蛇形绕障。
