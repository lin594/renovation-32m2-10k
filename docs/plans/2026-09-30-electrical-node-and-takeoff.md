## 1. PCT-42 / PCT-62 的正确计数语言

本项目以后只用“**回路对**”描述：

- **PCT-42：2进4出 = 1 对 L/N 输入 → 2 对 L/N 输出。**
- **PCT-62：2进6出 = 1 对 L/N 输入 → 3 对 L/N 输出。**
- 一个 PCT 已经同时包含 L、N 两极，**绝不再写“L一只、N一只”**。
- 具体内部孔位仍以到货实物标识/说明书为准；完全断电时可用 H31 通断档复核同极孔位关系。

所以选型只看这个节点最终要分出多少个 **L/N 支路对**：

- 2 路输出 → PCT-42；
- 3 路输出 → PCT-62；
- 超过3路，不硬堆一堆长线，优先把空间上接近的负载做成一个局部支路，再在局部可检修点二次分线。

## 3. 玄关 H1：PCT-62 塞不进四分线槽怎么办

这里要把你刚问的逻辑说清楚：

H1 本身需要 **3 对输出**：

1. 继续去 L1 的 6mm² L/N；
2. 去玄关设备架的 BVVB L/N；
3. 去玄关灯带/机械开关支路。

所以 H1 正确型号是 **PCT-62 ×1**，不是两只 PCT-42。

如果 PCT-62 连上线之后塞不进四分槽，处理非常简单：

> **设备架上方加一个约100×100×50带盖阻燃明装分线盒，里面只放这一只 PCT-62。**

设备架仍然由 H1 的第二路输出直接供电，不改变线路拓扑。

## 4. 三类复杂控制接法

### 4.1 厨房机械开关 K1

K1 的 PCT-42 正好有两个 L/N 输出通道：

**输出1：** 6mm² L/N 继续去 K2。  
**输出2：** 这里不是要求两根线必须去同一个器具，而是：

- 该极的 L 输出 → BVVB红芯 → 机械开关常火 L 下行；
- 该极的 N 输出 → 另一根BVVB蓝芯 → 厨房主灯 N。

机械开关返回：

- 开关出来的 Lsw → BVVB另一芯返回 K1；
- 再用 **1只2孔2.5mm²单极连接端子** 与去主灯的 L 相接。

因此 K1 只需要 **1只 PCT-42 + 1只2孔小端子**。

### 4.2 卧室 JZ-N2

B1 的一个 PCT-62 输出对只负责给 JZ-N2 送常电 L/N。

JZ盒内：

- L → JZ-N2 L；
- N → 4孔单极并联端子；
- N端子分给：JZ-N2 N、卧室主灯N、床下灯专用插座N；
- JZ-N2 L1 + N → 一根BVVB去主灯；
- JZ-N2 L2 + N → 一根BVVB去床下灯专用插座。

### 4.3 客厅 JZ-N2

与卧室同理：

- L1 的一个输出对 → JZ-N2常电L/N；
- JZ盒内N通过4孔单极端子分给 JZ-N2、主灯、餐灯；
- L1+N → 主灯；
- L2+N → 餐灯。

## 6. 明天现场只需要验证三件事

1. **PCT-42 / PCT-62 + 真实6mm² / 2.5mm²导线**到底能否进入四分槽或低轮廓配套分线件；
2. 罗马杆是否与高位主槽冲突；
3. 五条高位主干实际卷尺长度。

第1项决定盒子大小；第2项决定局部高度；第3项决定最终剪线长度。**分线器“2进4出/2进6出”的极数逻辑不再变。**
