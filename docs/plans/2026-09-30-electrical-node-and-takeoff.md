## 1. 先回答 H1：PCT-42 塞不进四分线槽怎么办

玄关设备架不依赖“端子必须塞进线槽”。

H1 位于玄关设备架上方。若 PCT-42 连真实导线后放不进四分线槽/低轮廓配套分线腔，则 **H1 增加一个约100×100×50mm的带盖阻燃明装分线盒**。盒内放：

- L：PCT-42 ×1；
- N：PCT-42 ×1；
- 两只端子彼此绝缘、分别固定。

每极实际使用 **1进3出**：

- 进：C3 从配电箱来的 6mm² 主干；
- 出1：6mm² 主干继续去 L1；
- 出2：BVVB 2×2.5 去玄关设备架常电；
- 出3：BVVB 2×2.5 去玄关灯带/开关支路。

所以“PCT-42 放不进线槽”只意味着 **H1 从低轮廓分线腔回退为明装分线盒**，不会改变设备架怎么供电，也不会改变主干路线。

> PCT-42 商品标称为“2进4出”时，本方案按“同一极的多孔并联分配端子”使用。到货后先在完全断电状态用 H31 通断档核对实物孔位关系，并以产品说明书为最终依据；若内部拓扑不是同极全并联，不按本表接线。

## 2. 九个主分支位置

## 3. 三类复杂控制接法

### 3.1 厨房机械开关 K1

使用两根BVVB完成：

1. **K1 → 开关**：红芯 = 常火L下行；蓝芯两端套红色标识 = Lsw返回；
2. **K1 → 厨房主灯**：红芯 = Lsw；蓝芯 = N。

K1内部：

- L-PCT：6mm²进 → 6mm²去K2 + 开关L；
- N-PCT：6mm²进 → 6mm²去K2 + 主灯N；
- 开关返回Lsw与主灯L，用一只正规2孔2.5mm²端子一对一连接。

不需要为90°转弯加盒。

### 3.2 卧室 JZ-N2

B1只给JZ-N2一根BVVB的常电 L/N。

JZ盒内：

- L → JZ-N2 的 L；
- N → 4孔2.5mm²并联端子；
- 该N端子分别给 JZ-N2 N、卧室主灯N、床下灯专用插座N；
- JZ-N2 L1 + N 用一根BVVB去卧室主灯；
- JZ-N2 L2 + N 用一根BVVB去床下灯专用二孔插座。

如果既有86暗盒放不下JZ-N2 + N分线端子，则使用延长框或相邻深明盒，不削细导体硬塞。

### 3.3 客厅 JZ-N2

L1给JZ-N2一根BVVB常电 L/N。

JZ盒内与卧室同理：

- L → JZ-N2 L；
- N经4孔端子分给JZ-N2 N、主灯N、餐灯N；
- L1+N 一根BVVB去客厅主灯；
- L2+N 一根BVVB去餐灯。

这样L1主PCT仍保持每极最多 **1进4出**，不用升级PCT-62。

### 4.3 6mm² BV/BVR

只用于：

- 主箱→副保护盒五路短馈线；
- C1/C2/C3三路6mm²高位主干。

- 主箱→副箱五路短馈线合计：约3.0m；

- C2：5.0m；
- C3：10.0m；

- 每极下料预算：约25m；
- L：买30m，足够；
- N：现有约60m蓝色6mm²若实物确认合格，预计使用约25m，余约35m。

### 4.5 端子

- PCT-42：**20只**（18只主节点 + 2只备用）；

### 4.7 固定件

目前已购护套线卡扣钉100只。
