# 公开仓库信息架构改造

## 目标

公开首页先展示现状与目标的前后对比，再给出实时资金、工期和安全边界。结构化数据继续作为唯一真源，避免为“好看”复制一套无法校验的信息。

## 设计

`README.md` 是项目故事和导航；`PROJECT_STATUS.md` 是从账本、预算、任务和采购自动生成的快照；`docs/editing-guide.md` 是低门槛修改入口。`diagrams/` 只保留当前图纸，编号只表达职责，旧图由 Git 历史承担。

不再生成或提交 PNG 预览。README 直接嵌入 SVG，浏览器使用本机中文字体渲染；CI 校验 SVG/XML 和生成一致性，不把某台渲染机缺少中文字体的问题固化进仓库。

账目既可由小型 CLI 安全追加，也可直接编辑 CSV。主分支 CI 只自动更新派生状态页，不改原始账本；Pull Request 只读校验。工作流使用最小权限，只有状态页同步任务拥有 `contents: write`。

## 内容扩展

客厅目标图把双人沙发改为可展开沙发床，并以虚线表达临时客卧占地和后期隐私帘候选。厨房增加已有洗碗机、三孔无PE标识插座、独立止水和排水门禁；其位置与受潮木柜冲突保持显式待现场确认。

## 验证

`make status && make diagrams && make check` 必须通过；测试检查图纸目录扁平、旧版目录不存在、沙发床/隐私帘/洗碗机图层存在、账本状态页与真源一致。推送前获取远端并确认主分支没有分叉。
