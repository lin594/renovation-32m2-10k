# 2026-08-31 第三方仓库合理性审计

- 审计结论：`仓库可继续用于规划，但方案尚未达到施工图或通电/入住批准状态`
- 审计范围：事实源、图纸职责、采购、预算、工期、风险、验收门禁、自动化校验和Git历史
- 审计视角：假设审计者未参与此前讨论，只依据仓库证据判断另一名执行者能否安全接手

## 做得合理的部分

1. `house.yaml`、账本、库存、采购、工期和风险已分源管理；实际支出只从`ledger.csv`汇总。
2. 图纸职责清楚。尤其31/32/33已把空间路径、五回路/PCT拓扑和卧室装配拆开，阳台禁入边界、设备架南墙锚点和吊扇暗线可被自动检查。
3. 10月主攻、10月后零专项往返、1月单人收尾符合交通成本约束，且保留了涂层固化失败时的降级路径。
4. 防猫纱窗、无PE、浴霸、燃气遮盖、潮湿和排水等主要风险没有被错误标成完成。

## 本次已修订的重大问题

1. **PCT额定值被过度简化。** `上级≤32A`只能说明未直接超过端子标称值，不能证明下游2.5mm²或1.5mm²获得适当保护。PCT被重新定义为连接器；保护器仍须匹配最小导线、敷设、负载和故障切断条件。
2. **PCT数量不是可直接下单的物理数量。** 图中数量是逻辑节点数；只有实物确认单件包含L/N独立极组时才成立，否则按内部母线拓扑重算。
3. **B10/C10不能单独批准1.5mm²。** 铭牌只作初筛，仍须结合线长、敷设、负载和产品由合格电工确认。
4. **两芯插座线不能解决PE。** BVVB 2×2.5mm²只含L/N；在供电系统、PE/PEN和等电位条件未确认前，三孔插座及空调、冰箱、洗烘机、燃气热水器等I类设备不得用新线路通电。
5. **DIY检查不能替代竣工检测。** 万用表/测电笔保留为辅助工具；绝缘电阻、插座接线、PE连续性/接地故障条件和漏保动作电流/时间由合格电工完成并留实测记录。
6. **取消跳过卫生间闭水。** 防水层固化后、铺砖前加入不少于24h蓄水试验；失败时修复重测，不为赶10月排期提前铺砖。
7. **4728元不是已证明足够的余额。** 新增七类未报价必需项和报价门禁；报价未齐前不下不可退的非必要订单，也不动用700元应急金掩盖已知缺口。
8. **自动化校验覆盖不足。** 增加枚举值、重复ID、电气五回路、PCT逻辑数量、14组插座、阳台边界、专业通电门禁和预算报价门禁检查。

## 仍未关闭、必须由现场证据决定的事项

1. 配电箱每个器件完整铭牌、供电系统类型、PE/PEN和卫生间等电位实际条件。
2. 两台空调、洗烘机、浴霸和厨房设备铭牌及同时负载；当前五回路是否可承担。
3. TYO PCT-42/PCT-62实物内部拓扑、认证、温升/导线适配和单件极组数量。
4. 防水准确型号、基层兼容、涂膜厚度、固化时间和蓄水结果。
5. 墙体潮湿来源、水槽排水漏点、洗衣机/马桶共管排水测试。
6. 防猫纱窗、三扇门、马桶、基本地面及电气服务/材料总报价。
7. 架空瓷砖灶台与燃气管遮盖方案；风险关闭前不得安装。

## 接手判断

第三方现在可以依据仓库完成线上询价、购物车、预约和10月1日复测，但不能仅凭图纸开始固定电路通电、铺设未验证防水上的瓷砖、遮盖燃气管或确认三猫入住。下一次“可施工”判断必须附现场照片、铭牌、产品说明、报价以及专业检测/服务方结论。

## 审计依据

- [GB 55024-2022官方发布页](https://szwb.sz.gov.cn/gwszwfw/zsk/hybz/content/post_9913357.html)：该规范为强制性工程建设规范；仓库据此把电气竣工检测和PE风险升级为阻断项。
- [南京市工程质量监管要点](https://sjw.nanjing.gov.cn/gdzsj/zcfg/bmgz/202310/P020231205538392959282.pdf)：列明插座接线、PE不得经插座串联以及L/N不得利用插座端子转接供电等实施要点。
- [武汉市明敷与接线盒要求](https://scjgj.wuhan.gov.cn/jggg/tzgg/202412/P020241203398786852173.pdf)：明敷市电线路应有保护，导管内不设接头，接头位于可检修接线盒。
- [住宅卫生间蓄水试验技术文件](https://www.xiongan.gov.cn/1212407566_17319236611251n.pdf)：防水层完成后第一次蓄水不少于24h；仓库采用其作为不跳过铺砖前验证的最低门禁参考。
