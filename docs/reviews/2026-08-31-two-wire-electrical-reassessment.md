# 2026-08-31 无PE两线制与V5仓库复核

- 复核结论：`仓库已一致表达既定两线制和分级漏保方案，可继续远程选型与10月复测；仍不是施工图或通电批准`
- 复核视角：未参与方案讨论的第三方，仅依据当前主数据、采购、预算、工期、风险、V5图纸和自动化校验判断能否接手
- 取代范围：更新首次审计中“PE/PEN状态尚待确认、三孔面板全面阻断”的事实前提；首次审计的燃气、防水、预算和专业检测门禁继续有效

## 本轮确认的架构

1. 配电箱仍恰好为3个RCBO和2个MCB。RCBO-01供卧室，RCBO-02供厨房，RCBO-03供客厅/洗烘/冰箱/玄关；MCB-04合并全部非卫浴照明，MCB-05只作卫生间专用馈线。
2. MCB-05经E-HOLE-03后先进入RCD-BATH-01双极30mA末端漏保，才分浴霸、智能除雾镜柜和防潮照明。漏保箱前线路连续、无接头、无分支；室内无合格干区时移到走廊A门外。
3. 两台空调和洗烘机各有设备级插座式漏保候选。上下级漏保允许非选择性同时动作，分别测试，不宣称具备选择性。
4. 三孔面板可以进入方案，但PE端子保持未连接并粘贴“本户无PE”标识；N/PE短接、借用水管/燃气管和把漏保写成接地替代均被自动化规则禁止。
5. PCT只保留六个逻辑节点。PCT-42/PCT-62及检修盒实购数量必须按实物L/N极组、认证、导线适配和保护器重新换算。

## 第三方发现并已修订的问题

1. 库存和主数据仍保留“蓝色6mm²线用胶布改作相线”的旧提案，已统一改为只作中性导体或其他与蓝色标识一致的用途候选。
2. 扫地机库存仍写“位置待定”，现已同步为沙发与书桌之间；低位常电和上部沙发充电保持两个独立插座点。
3. 浴室柜采购项没有体现智能除雾镜柜和电源要求，现已合并到BUY-0005并引用RCD-BATH-01下游连接点。
4. 两芯BVVB采购说明仍等待不存在的PE方案关闭，现已改成明确无PE标识、保护器匹配和专业实测门禁。
5. 基础电料预算范围没有列出新增设备级/卫浴末端漏保，现已并入BQ-07；4728元仍只是上限，不能据此判断买得下。
6. YAML校验原先不能识别同一mapping中的重复键，现已直接检查Psych语法树并报出文件与行号。

## 仍未关闭的施工阻断项

1. 五个配电器件完整铭牌、MCB-04/05额定值和最小导线匹配尚无现场证据。
2. 两台空调、浴霸和最终洗烘机的功率、插头、启动/变频特性以及候选漏保产品说明尚未取得。
3. 卫生间喷溅范围和可用干区尚未实测；“高位”不能单独关闭位置风险。
4. BQ-07及其他六类必需项尚未形成含送装/辅料报价，新增保护器可能进一步压缩4728元余额。
5. 新线路仍须由合格电工完成绝缘、极性、保护器/最小导线匹配、插座接线和各级漏保动作电流/时间测试。
6. 无PE是被接受的长期剩余风险，不会因上述测试或三孔面板外形转为“接地合格”。

## 接手判断

第三方现在可以依据V5完成线上产品筛选、预约电工、准备铭牌/说明书清单和10月1日测量表；不得提前下单PCT数量、卫生间保护器或与设备铭牌相关的末端漏保，也不得仅凭V5进行端接和通电。
