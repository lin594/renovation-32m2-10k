# 2026-09-01 公开仓库第三方审计

结论：仓库已经从“主要供 AI 维护的资料集合”调整为“人可读、人可改、机器可校验”的公开项目；仍是装修讨论与管理资料，不是施工许可。

## 已修订

1. README 首屏并列现状图和目标布置图，直接使用浏览器可渲染中文的 SVG；无中文字形的本地 PNG 预览已删除。
2. `diagrams/` 只保留 11 张现行图纸，不再同时维护 v4、v5 和 archive；历史版本由 Git 提供。
3. 实际金额只录入 `data/ledger.csv`。`PROJECT_STATUS.md` 自动计算支出、收入、净流出、预留和剩余上限，删除预算与工期文件中的重复金额快照。
4. 新增账本 CLI、人类编辑指南和 GitHub Actions。CI 对 Pull Request 只读校验；主分支仅允许机器人更新派生状态页，不改原始账本。
5. 沙发改为可展开沙发床，图中表达临时客卧占地和后期可收起隐私帘候选。
6. 洗碗机明确为已有物资，叠放在水槽北侧二层木柜或同位置替代柜上；进水来自水槽进水处独立开关，排水软管直接入水槽。
7. 端子最低 SKU 改为 PCT-62 二进六出一包和五孔接线型一包。PCT-62 每只分 3 组 L/N；PCT-42 首批不买，串联型只作条件购物车。

## 仍需保持开放

1. GitHub 仓库设置若禁止 Actions 写入，自动状态提交会失败；需在仓库 Actions 设置中允许工作流写入内容。工作流本身已按 job 使用最小权限。
2. `PROJECT_STATUS.md` 是现金流视角，未把尚未下单的询价或计划金额当作支出；采购承诺金额需要未来在报价数据完整后单独建模。
3. 8 笔历史账目目前均缺日期，金额正确但无法形成准确现金流时间线。
4. 五孔接线型目前只知道硬线最大 4mm²，额定电压、电流、认证和温升条件仍未知；未核验前不能下单或代替保护器。
5. 洗碗机叠放方案必须以设备说明、柜体承重/水平/抗振、排水软管固定和插座防溅复测为准。受潮木柜不能仅因“位置合适”就判定可继续承载。
6. README 静态展示页可以进一步升级，但本轮只保留为 GitHub Issue 范围，不引入 Pages 或前端依赖。

## 接手判断

不熟悉项目的人现在可以从 README → PROJECT_STATUS → 两张前后图进入，再按编辑指南记账或更新状态。AI 仍可依靠 YAML/CSV、稳定 ID、跨文件引用和测试继续辅助；公开展示层没有成为第二套真源。
