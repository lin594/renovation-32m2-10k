# 0004：采用分区无主灯并把EVE V固定为玄关家庭中枢

- 状态：已采纳（电气参数待现场冻结）
- 日期：2026-08-31

## 背景

房屋无吊顶，希望用分散、低眩光的灯具取代单一主灯，并尽量减少旧房明装线路的成本和视觉负担。走廊A南墙将设置光猫、Wi-Fi设备架；已有EVE V1触屏损坏但显示正常，业主确认可以长期运行。配电箱器件的完整铭牌尚未取得，老小区无保护地线也只是口述信息。

## 决策

照明按空间分区控制，但不为每盏灯单独设置配电箱回路。现有配电箱支路位置固定为3个漏保和2个空开，共五路；第4、5位受物理空间限制只能安装空开，不能改装漏保。回路分配以实际穿线孔方向优先：卧室漏保从E-HOLE-01进入卧室并承担卧室插座/空调；厨房漏保经E-HOLE-02进入厨房并承担厨房插座/设备；客厅+卫生间漏保沿走廊A向南，在E-HOLE-03进入卫生间、E-HOLE-04进入客厅，位于客厅的洗烘机随客厅，玄关常电设备架也从该南向漏保主干就近分支。

两只空开全部用于固定照明：第4路为空开“北向照明”，在配电箱处分成两支，经E-HOLE-01和E-HOLE-02分别进入卧室、厨房；第5路为空开“南向/公共照明”，覆盖走廊A/B、客厅、阳台并经E-HOLE-04进入客厅。卫生间照明仍随第3个漏保经E-HOLE-03进入，不放到无漏保空开上。这样五路全部被利用，避免把方向相反的卧室和客厅合并，同时任一照明空开跳闸时仍保留另一方向的基础照明。两只空开虽不能改成漏保，但若现有铭牌确为36A，必须换成同宽且与1.5mm²照明线和实际敷设条件匹配的空开，不能直接使用36A保护1.5mm²线路。

走廊A采用220V柔性灯带候选方案。为了利用第5路南向照明空开的短路径，可以在具体产品明确支持固定接线时，让受MCB-02控制的建筑线进入可检修带盖接线盒，在盒内连接厂家专用整流/电源接头，再接灯带；这属于固定灯具接线，但不等于建筑线可以直接接触灯带铜箔或任意软引线。备选是购买带成型插头的完整灯带，插入由RCBO-03供电的玄关智能插座。两种方式都必须使用匹配的末端封帽、固定和应力消除，接头不得埋入腻子或不可开启线槽。

EVE V1固定放在玄关设备架，使用架内短网线连接路由器，承担Home Assistant主机、电子相册和玄关信息显示器。设备架至少提供四个常电插位；光猫、路由器和EVE V不得接入可能被照明自动化关闭的插座。9月完成72小时运行、断电恢复、虚拟机与Home Assistant自启动、有线网络和远程桌面测试。

线材基线暂定为：1.5mm²仅用于照明候选支路，普通插座不小于2.5mm²，空调、厨房和洗烘机按设备铭牌、线路长度及敷设条件核算。6mm²主干不能替代下游支路保护；1.5mm²不得直接挂在未经核实的36A保护器后。剩余蓝色6mm²线优先只作为中性导体候选，端部胶布改色不能自动批准其作为相线。

接线端子不按“250V 32A”单一参数采购。2孔用于进出直通，3孔用于主干继续并分一支，5孔用于同回路多分支；6mm²主干向多个独立回路分配时使用匹配的DIN导轨分配块并由各回路保护器分别保护。所有端子须位于可开启接线盒或配电箱内并固定。

## 现场冻结门禁

2026年10月1日拍摄所有配电器件正面和侧面铭牌，记录额定电流、脱扣曲线、极数、漏电动作电流、分断能力和型号；同时复测线路长度、同槽导线数量及走廊A灯带长度。完成这些输入后才冻结最终回路表、线色和线径、保护器匹配、端子一分几数量及逐房间材料包。急缺标准小件使用京东次日补购，不为赶9月采购而猜测电气参数。

## 影响

玄关集中网络设备和家庭中枢能减少跨房间网线，并让EVE V屏幕继续产生价值。220V灯带省去独立低压驱动器，但其接头直接处于市电电压，产品完整性和可检修端接比24V方案更重要。电气方案在现场门禁关闭前仍是讨论基线，不得视为施工图或通电批准。
