# 0004：采用分区无主灯并把EVE V固定为玄关家庭中枢

- 状态：部分被0006取代（无主灯与玄关中枢保留；原MCB-04/05照明分工及PCT数量失效）
- 日期：2026-08-31

## 背景

房屋无吊顶，希望用分散、低眩光的灯具取代单一主灯，并尽量减少旧房明装线路的成本和视觉负担。走廊A南墙将设置光猫、Wi-Fi设备架；已有EVE V1触屏损坏但显示正常，业主确认可以长期运行。配电箱器件的完整铭牌尚未取得，老小区无保护地线也只是口述信息。

## 决策

照明按空间分区控制，但不为每盏灯单独设置配电箱回路。现有配电箱支路位置固定为3个漏保和2个空开，共五路；第4、5位受物理空间限制只能安装空开，不能改装漏保。回路分配以实际穿线孔方向优先：卧室漏保从E-HOLE-01进入卧室并承担卧室插座/空调；厨房漏保经E-HOLE-02进入厨房并承担厨房插座/设备；客厅+卫生间漏保沿走廊A向南，在E-HOLE-03进入卫生间、E-HOLE-04进入客厅，位于客厅的洗烘机随客厅，玄关常电设备架也从该南向漏保主干就近分支。

两只空开全部用于固定照明：第4路为空开“北向照明”，在JB-L4使用PCT-42分成卧室、厨房两支；第5路为空开“南向/公共照明”，在JB-L5使用PCT-62分成走廊A灯带、走廊B灯和客厅灯。卫生间照明仍随第3个漏保经E-HOLE-03进入，不放到无漏保空开上。阳台没有穿线孔，本期不钻孔、不夹移门布线，也不设置永久220V线路。B10/C10铭牌只作为1.5mm²保护的初筛，仍须由电工结合敷设、线长和负载确认；未通过就不安装固定照明，走廊灯带改用第3漏保常电插座加智能插座，其余空间暂用插接式灯具。

走廊A采用220V柔性灯带候选方案。为了利用第5路南向照明空开的短路径，可以在具体产品明确支持固定接线时，让受MCB-05控制的建筑线进入可检修带盖接线盒，在盒内连接厂家专用整流/电源接头，再接灯带；这属于固定灯具接线，但不等于建筑线可以直接接触灯带铜箔或任意软引线。备选是购买带成型插头的完整灯带，插入由RCBO-03供电的玄关智能插座。两种方式都必须使用匹配的末端封帽、固定和应力消除，接头不得埋入腻子或不可开启线槽。

EVE V1固定放在玄关设备架，使用架内短网线连接路由器，承担Home Assistant主机、电子相册和玄关信息显示器。设备架至少提供四个常电插位；光猫、路由器和EVE V不得接入可能被照明自动化关闭的插座。9月完成72小时运行、断电恢复、虚拟机与Home Assistant自启动、有线网络和远程桌面测试。

线材改用护套线为主，不再把蓝色单芯线改色作为新购分支方案。现在先购BVVB 2×2.5mm² 50m一卷，估算净用量42～45m；10月1日按墙面实路复测，净长超过45m才用京东补第二卷。BVVB 2×1.5mm² 50m和1×1.5mm²控制线只加入购物车；B10/C10仅作初筛，仍须由电工结合敷设、线长和负载确认后才购买，控制线颜色也按现场规则冻结。不采用全屋2.5mm²照明，因为它增加线槽和盒内拥挤，也不能解决保护器不匹配。

PCT拓扑的逻辑节点固定为：JB-L4使用PCT-42；JB-L5、JB-R3、JB-BED、JB-KIT、JB-LIV使用PCT-62，另预留一个PCT-62备用。每个节点安装在独立、带盖、可检修的约100×100×50mm明装盒中。PCT标称32A是每极全部端口的总电流，但上级≤32A只是必要条件；保护器还必须匹配最小下游导线在实际敷设下的允许值、负载和故障切断要求。PCT只是连接器，不提供保护。图上的“1只”只有在实物确认单件包含L/N独立极组时才成立，否则按内部拓扑重算数量。L、N及未来可能存在的PE使用独立极组/端子。

插座按14组作为路线估算基线：卧室3组、厨房3组、客厅7组、玄关设备架1组（至少4个常电位），卫生间不新增普通插座。扫地机器人点位保持TBD并计2m余量。卧室西墙原暗盒只安装吊扇调速器，床南在其旁设置独立明装插座盒，床北另设明装插座；不同回路分盒、分线槽、分端子。插座由PCT分出短尾线，每个插座端子只压一根导线。普通插座保持常电，智能插座作为可拔插设备使用，智能墙壁开关只控制灯具。两芯L/N不提供PE，漏保也不能替代PE，三孔插座和I类设备继续保持“无PE未验收”。

## 现场冻结门禁

2026年10月1日拍摄所有配电器件正面和侧面铭牌，记录额定电流、脱扣曲线、极数、漏电动作电流、分断能力和型号；同时复测2.5mm²净路线、同槽成品线缆外径及走廊A灯带长度。逐一确认PCT节点的直接上级≤32A，并确认两只照明空开是否满足1.5mm²门禁。急缺标准件使用京东次日补购，不用提前囤线替代保护匹配。

## 影响

玄关集中网络设备和家庭中枢能减少跨房间网线，并让EVE V屏幕继续产生价值。220V灯带省去独立低压驱动器，但其接头直接处于市电电压，产品完整性和可检修端接比24V方案更重要。电气方案在现场门禁关闭前仍是讨论基线，不得视为施工图或通电批准。
