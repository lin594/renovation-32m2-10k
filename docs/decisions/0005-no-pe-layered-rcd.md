# 0005：无PE两线制采用分级漏保并显式保留剩余风险

- 状态：已采纳
- 日期：2026-08-31

## 背景

房屋位于开封老小区四楼，户内已确认只有相线L和工作零线N，没有可用保护导体PE，也无法由单户独立增设接地。继续把“确认或补建PE”作为方案前置条件，会让仓库长期停留在无法执行的状态；反过来，把漏电保护器描述为PE替代品也会掩盖真实风险。

## 决策

在不改配电箱五个支路位置的前提下，采用“支路保护器＋高风险设备末端剩余电流保护”的分级方案。允许安装三孔面板，但PE端子保持未连接，并粘贴持久“本户无PE”标识；不得把三孔外形、两芯线路或漏保记录为接地验收合格。

严禁N与PE短接，严禁利用水管、燃气管或其他金属构件作为接地。上下级30mA漏保允许非选择性动作，接受故障时可能同时跳闸；分别测试并记录，不宣称能够只切断末级。

## 设备边界

- 空调、洗烘机使用确有剩余电流检测、TEST/RESET和L/N双极切断能力的设备级保护产品；过欠压、计量或普通智能插座不能冒充漏保。
- 卫生间专用馈线在可检修干区先经过双极30mA末端漏保，再连接浴霸、镜柜和照明。
- 设备说明只允许固定接线时，使用双极隔离开关和带盖接线盒，不擅自改装插头。
- 智能开关和智能插座不承担漏电、短路或过载保护职责。

## 验收与剩余风险

无PE事实由业主明确接受，但新建线路通电前仍须由合格电工完成绝缘、极性、保护器与最小导线匹配、插座接线以及各级漏保动作电流/时间测试。该检测证明线路和保护器按当前两线制方案工作，不等同于证明存在PE。

参考：国家标准信息公共服务平台列明现行[GB/T 28527-2012 插座式剩余电流电器（SRCD）](https://std.samr.gov.cn/gb/search/gbDetailed?id=71F772D7FC46D3A7E05397BE0A0AB82A)。
