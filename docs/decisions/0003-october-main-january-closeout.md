# 0003：采用9/28–10/4主攻、1月单人收尾且中间零专项往返

- 状态：已采纳
- 日期：2026-09-26
- 更新：取代本文件2026-08-31版本中的“10/1–10/8主窗口”日期；“主窗口集中判断、1月只做冻结收尾”的原则不变。

## 背景

主负责人常驻北京，房屋位于开封，每次装修专项往返约700元。当前行程为9月27日夜间出发、9月28日早抵达开封，9月28日至10月4日作为本轮主现场施工窗口。2027年1月中旬回开封后预计仅有一名非主负责人能够连续DIY。总装修预算仍为10000元，三猫安全入住优先级最高。

## 决策

把2026年9月28日至10月4日设为当前主施工窗口。9月28日优先完成全屋复测、电气专业门禁、门窗/防猫纱窗复测、厨房/客厅受潮与顶楼西南角天花板疑似雨漏排查，并按预约回收4扇旧铁门。卫生间防水固化后、铺砖前须安排不少于24h蓄水试验。

9月29日至10月2日并行推进卫生间湿作业与可施工区域墙面：墙体整体大体平整，只做必要的局部腻子修补和局部打磨，不追求装修公司级全屋厚找平。漏源未关闭或仍潮湿的区域允许跳过。10月2日至3日优先推进石塑地板主要区域；10月3日只有在乳胶漆达到厂家允许安装/触碰条件后才安装明线和灯具，并安排电工终检。10月4日只做总验收、保洁、留档与返程缓冲，不再开启不可中断的新施工。

明线和地板若受固化时间限制未能全部完成，必须在离场前完成首段示范、尺寸、端点及材料编号。电气收尾不得简单留给1月单人：非主负责人只能断电完成线槽/明盒等机械收尾，保护/PE结论、端接和通电须由合格电工复核检测。

主窗口结束后至2027年1月中旬不安排装修专项往返，也不依赖代理人执行需要现场判断的施工。1月由一名非主负责人接收门窗商安装、完成已编号收尾、购买含安装马桶并保洁。理想三猫入住日为2027年1月15日，硬截止为2027年2月7日。

## 涂装与高处边界

乳胶漆面积口径更新为：层高按2.8m、阳台只刷顶、厨卫1.8m以下瓷砖区不刷。当前未扣三处主要外窗约123.99㎡。小建刷新S2暂定1875（近可可蛋奶），计划3桶底漆、4桶同色同批面漆和1套卖家工具；4桶面漆按卖家“约30㎡两遍/桶”口径接近上限，下单前需客服再次确认。

业主明确恐高，不自行上屋顶或进行临边作业。客厅西南角天花板疑似顶楼雨漏时，室内只做水迹记录、松动基层清理和明确点/缝的局部背水面处理；持续雨漏的屋面迎水面维修交物业/防水人员。

## 影响

该方案把原8天窗口压缩为7天，对固化和并行组织要求更高，因此“完成度”让位于安全门禁和不可逆关键路径。闭水不通过不铺砖，涂层未达到安装条件时不强装明线，电气专业门禁未关闭时新线路保持断开。洗烘机、浴室柜、衣柜架及非必要软装按既定顺序延期，防猫纱窗、防水、基本地面、马桶和经检测的基础用电不因预算压缩而取消。
