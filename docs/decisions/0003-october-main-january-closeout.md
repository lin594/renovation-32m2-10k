# 0003：采用10月主攻、1月单人收尾且中间零专项往返

- 状态：已采纳
- 日期：2026-08-31

## 背景

主负责人常驻北京，房屋位于开封，每次装修专项往返约700元。2026年10月1日至8日有两名DIY人员且主负责人在场；2027年1月中旬回开封后预计仅有一名非主负责人能够连续DIY。总装修预算为10000元，三猫安全入住优先级最高。

## 决策

把2026年10月1日至8日设为唯一双人主施工窗口。卫生间防水固化后、铺砖前须安排不少于24h蓄水试验；全屋基层与乳胶漆、涂层小样判断、明线线路设计和地板方向等高判断或高耦合事项均在10月完成。明线和地板若受固化时间限制未能全部安装，必须在离场前完成首段示范、尺寸、端点及材料编号。电气收尾不得简单留给1月单人：非主负责人只能断电完成线槽/明盒等机械收尾，保护/PE结论、端接和通电须由合格电工复核检测。

2026年10月8日离场后至2027年1月中旬不安排北京—开封装修专项往返，也不依赖代理人施工。1月由一名非主负责人接收门窗商安装、完成已编号收尾、购买含安装马桶并保洁。理想三猫入住日为2027年1月15日，硬截止为2027年2月7日；防猫纱窗、地面收边、涂层固化和清洁等门槛未全部满足时，人和猫继续住2km外的另一住所。

乳胶漆按约134.70㎡未扣外窗的保守基数提前采购3桶底漆、5桶同色同批面漆和1套工具，计划2012元。补录地砖后，以已支出1860元、10月交通700元、涂装2012元和应急金700元计算，其余工作预算门禁为4728元。

## 影响

该方案减少10月后的专项交通支出并把现场判断集中在主负责人在场期，但8天排期紧，任何渗漏、潮湿、产品固化、蓄水失败或基层问题都可能降低完成度。为避免赶工伤害质量，闭水不通过不铺砖，涂层未达到安装条件时不强装明线，电气专业门禁未关闭时新线路保持断开。洗烘机、浴室柜、衣柜架及非必要软装按既定顺序延期，防猫纱窗、防水、基本地面、马桶和经检测的基础用电不因预算压缩而取消。
