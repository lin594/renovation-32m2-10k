# 0002：高风险施工项必须经过安全门禁

- 状态：已采纳
- 日期：2026-08-31

## 背景

项目以低成本、高性价比为目标，但现场存在无地线、卫生间浴霸、燃气管遮蔽、燃气热水器、水路共管和自制灶台支撑等不确定条件。若把“已有”“计划”直接解释为“可施工”，容易在省钱过程中放大人身和验收风险。

## 决策

安全相关问题统一进入 `data/risks.yaml`。风险关闭必须包含：现场事实、缺失信息、核验人或机构、可接受条件及证据。`critical` 或 `high` 风险未关闭时，相关任务可继续测量、询价和比较方案，但不得标记为可施工或已验收。

漏电保护、延时送电、胶布改色、口头施工经验等不能单独作为关闭无地线或导体识别风险的证据。燃气设施以所在地燃气服务方验收要求和实际设备资料为必要输入。

## 影响

该门禁可能增加少量检测和沟通成本，但能减少返工、拒绝验收、设备损坏及人身风险。风险登记不是断言现方案一定违法或危险，而是明确在信息不足时不能提前批准。
