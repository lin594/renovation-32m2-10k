# 0008：DIY优先的空间主干、分布式T接与两路末端总漏保

- 状态：当前执行基线，待 2026-09-28 现场铭牌、负载、线径和路线复测
- 日期：2026-09-27
- 取代：0004/0006 中的回路分工；0007 的固定 PCT 最低采购组合

## 目标

本轮强电设计的第一优先级不是教科书式功能分离，而是让业主能够以全屋明装方式低复杂度自行敷设：减少重复穿同一墙洞、减少多条长距离并行线路、减少集中大分线盒、减少把粗线塞进普通插座/开关盒。安全门禁不因此降低；所有新建固定线路在保护器、线径、端子和检测条件未核验前不得通电。

## 五回路

1. **RCBO-01 卧室空间主干**：卧室普通插座、已有空调、固定照明和吊扇。只经 E-HOLE-01 一次进入卧室，沿墙连续主干，就地 T 接短支线。
2. **RCBO-02 厨房空间主干**：厨房插座、固定设备和固定照明。只经 E-HOLE-02 一次进入厨房，沿主要设备墙连续敷设。
3. **RCBO-03 客厅生活长主干**：玄关设备架常电、走廊A/B生活照明、客厅普通插座、洗烘一体机和客厅普通照明。经 E-HOLE-04 后沿客厅生活区一侧连续绕行。
4. **MCB-04 客厅高负载短主干**：只承担客厅空调和冰箱。与 RCBO-03 在走廊A至 E-HOLE-04 前可共用物理路径但 L/N 始终完全独立；过门洞后走另一侧短路径并就地T分。客厅空调端和冰箱端分别使用真正的 **≤30mA、L/N双极切断、带TEST/RESET** 的末端漏保型插座/空调伴侣，不再设置共用RCD-LIV-01小箱。这样任一设备漏电不会顺带切断另一设备。
5. **MCB-05 卫生间专用馈线**：MCB-05 至 **RCD-BATH-01** 之间连续、无任何负载分支。RCD-BATH-01 优先装在走廊A卫生间门外的 2~4 位 DIN 明装小箱；其后再进入卫生间，统一保护浴霸、浴室柜/镜灯和基础照明。只有产品说明、安装区域和防护条件都确认合格时，才考虑把该漏保放进卫生间干区。

RCD 在本项目口语中即“漏保”类别；MCB 负责过载/短路，RCD 负责剩余电流保护。RCD 不能替代 PE，本户仍按既定两线制无可用 PE 现实条件管理，严禁 N/PE 短接或借水管、燃气管接地。

## 物理施工语言

不再以“配电箱 -> 集中JB -> 多支放射线”为默认拓扑，而改成：

> 顶边/高位连续主干 -> 高位可检修盒内 T 接 -> 垂直支线下落到低位插座/开关；高位设备就近短接。

优先让主干不断。由于本户绝大多数用电点位在坐姿/手部高度，T 接节点原则上不放低位插座盒，而放在对应点位上方的高位主干旁带盖可开启接线盒中；低位插座盒只接一根末端支线。投影仪等高位设备可直接从高位主干就近分支。新建普通插座、照明和开关短支线默认统一采用适用于固定敷设的 2×2.5mm² 两芯护套线；开关盒一律把 L/N 带到位，但面板不必全部智能化。普通设备端子只接短尾线，尽量避免 6mm² 主干直接进入普通设备端子。

T 接/分支连接器必须明确适用于 220V 固定建筑布线和铜导体，具有清晰额定电压、电流、主线/支线截面范围与合格证明。是否“免剥”不是采购目标；允许按正规产品说明局部剥绝缘后机械压紧。**汽车线束类廉价穿刺夹不得用于本项目固定住宅布线。**

## 6mm² 蓝色库存线

约 60m 蓝色 6mm² 铜线只作为中性导体候选。优先评估是否在 RCBO-03 等长路径中作为 N 主干有施工价值，但：

- 不因主干变粗而提高上游保护器额定值；
- 缩径后的最小导线仍必须得到适当过流保护；
- 端子、线槽、弯折和检修空间不合适时宁可不用；
- 单相两线回路中若采用蓝色6mm² N，则同时购买/使用等截面的合规相色6mm² L；不靠红胶带把蓝线改作相线。

## 现场冻结项

2026-09-28 到现场后，至少确认：五个支路器件完整铭牌；两台空调、洗烘、浴霸及待购浴室柜/镜灯的负载信息；库存 6mm² 的实际线种；四个穿线孔和各连续主干的真实长度；候选 T 接端子的线种/截面适配、认证和额定值。

本轮不再为照明单独缩到1.5mm²；默认与普通小支线一起使用2.5mm²，以减少SKU、端子适配和现场判断。仍须核对智能开关、普通开关、吊扇调速器和灯具端子是否允许2.5mm²导体。

## 影响

此方案主动牺牲一部分“全屋独立照明回路”的整齐性，换取显著更少的重复穿洞和长距离并行布线。客厅门洞 E-HOLE-04 成为自然物理分流点：RCBO-03 向生活区绕行，MCB-04 只去空调/冰箱。卫生间保留独立馈线，使浴霸、浴室柜和照明尚未最终选型时仍可在门口总漏保之后灵活调整，而不影响全屋主干。


## 智能开关策略补充

布线按“全部智能化就绪、面板按价值选择”处理：所有固定照明开关盒都到达L/N，便于以后替换零火智能开关；本期优先把玄关/走廊A、客厅主要固定照明做智能控制，卧室按实际需求选择，厨房、卫生间和走廊B可直接使用普通机械开关以节省预算和降低故障依赖。
