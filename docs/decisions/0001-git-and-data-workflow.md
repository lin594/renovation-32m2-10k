# 0001：使用 Git 与文本数据管理装修全流程

- 状态：已采纳
- 日期：2026-08-31

## 背景

项目由业主直接策划，持续产生户型修正、方案选择、采购、收支、进度和现场风险。聊天记录无法稳定承担唯一事实源。

## 决策

使用 Git 管理所有文本数据和 SVG。小型、确定更新直接进入 `main` 并形成原子提交；多方案探索使用 `design/<topic>` 分支。实际收支只记录在 `data/ledger.csv`，其他文档只引用计算结果。重要选择使用编号决策记录。

提交格式为 `<类型>(<范围>): <中文摘要>`。装修领域允许使用中文类型：`建档`、`更新`、`修正`、`设计`、`记账`、`采购`、`进度`、`风险`、`文档`、`维护`。

## 影响

优点是可审计、可回滚、易于脚本检查；代价是每次现场变化都必须同步数据并提交。照片和可再生成预览默认不纳入 Git，防止仓库快速膨胀。
