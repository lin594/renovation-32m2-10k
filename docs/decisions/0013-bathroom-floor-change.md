# 0013：取消卫生间自铺地砖，闭水后改铺环氧

- 状态：已实施，后续增厚暂定
- 日期：2026-10-06
- 取代：0003/既有计划中的本轮卫生间自铺地砖部分

## 已确认事实

10月主窗口已经放弃卫生间自铺地砖方案。此前购买的30×30cm地砖12块没有铺，保留、转用或处置待定。2026年10月3日以75.33元购买米黄色环氧彩砂自流平地坪漆2组，每组1.4kg；业主确认在S2防水层闭水试验通过后已完成施工。

## 暂定方向

现有2.8kg环氧层作为卫生间地面饰面保留。业主计划2027年1月再购5kg增加厚度；增厚前须记录现有层固化、附着、防滑和积水点，并核对准确SKU、跨月重涂间隔、清洁/打磨、底涂、层间附着、总厚度和完整固化要求。

## 不变的安全边界

环氧饰面不是防水层；本次顺序已确认是闭水试验通过后再施工环氧。闭水时长、水位和照片仍待归档；跨月增厚和最终排水/防滑验收继续记为 `blocked`。
