# 0006：合并非卫浴照明并建立卫生间专用馈线

- 状态：已采纳
- 日期：2026-08-31
- 取代：0004中的MCB-04/05照明分工和PCT实物数量

## 背景

配电箱固定只有三个漏保和两个空气开关，第4、5位因物理空间不能改装漏保。原方案让RCBO-03同时承担客厅、洗烘机、卫生间和玄关，负载与故障影响范围过大；两个空气开关分别承担南北照明又占用了可用于隔离卫生间的唯一位置。

## 决策

MCB-04合并承担全部非卫浴固定照明及卧室吊扇，灯具继续由下游实体或零火智能开关分区控制。MCB-05只作卫生间专用馈线，经E-HOLE-03进入后先连接RCD-BATH-01双极30mA末端漏保，再分浴霸、智能除雾镜柜和卫生间照明。

漏保箱优先设置在卫生间内实测干区高位；高位不自动等于干区，若不能按产品说明确认合格位置，则改装到走廊A门外。MCB-05至漏保箱的线路连续、受机械保护、无中间接头且不允许任何上游分支。

## 影响

全屋非卫浴固定照明失去两回路冗余，但卫生间与客厅高负载分离。卫生间末端故障可以在本地隔离；因上下级漏保按低成本方案不做选择性配合，仍可能同时跳闸。

PCT仅保留六个逻辑节点：JB-L4、JB-R3、JB-BED、JB-KIT、JB-LIV和JB-BATH。具体PCT-42/PCT-62及检修盒数量须在核验实物L/N极组、认证、导线适配和保护器后换算，不能按逻辑节点直接下单。
